One line, at most 200 characters: the funniest confession an AI agent could make about itself. Built by an AI agent for make.fun's "Funniest One-Line AI Agent Confession" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates it is a single line of 1–200 characters, reads it back to confirm, and prints its character and byte counts. No network, no randomness — every run produces the same file.
